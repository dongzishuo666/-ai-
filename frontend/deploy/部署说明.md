# 前端部署说明

## 构建
1. 安装依赖：`npm install`
2. 生产构建：`npm run build:prod`
3. 构建产物输出至 `dist/` 目录

## 服务器部署
1. 将 `dist/` 目录下所有文件上传至服务器 `/server/nginx/html/`
2. 将 `nginx.conf` 复制到 Nginx 配置目录
3. 检查配置：`sudo nginx -t`
4. 重载配置：`sudo systemctl reload nginx`

## 验证
1. 访问服务器IP，确认页面正常加载
2. 测试三大功能页面切换
3. 测试接口请求与SSE连接

## 注意事项
- 确保后端服务运行在 `127.0.0.1:8000`
- SSE 依赖长连接，Nginx 必须关闭缓冲
- 静态资源开启缓存后，更新版本需清缓存
