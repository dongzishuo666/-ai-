# DESIGN.md · 多AI协助系统三大功能介绍

## 0. 风格推导依据
用户未指定风格，也未命中学术 / 商务咨询 / 政务三个预设分支（本主题为 AI 系统架构介绍），走通用设计原则。依据主题「多模型协作 + 程序化校验 + 轻量化工程」推导：深海军蓝主色（秩序、可信）+ 科技蓝辅色（连接、调度）+ 青绿强调（校验、裁决生效）。全程统一，不允许个别页特殊处理。

## 1. 画布与母版（具体 px）
- 画布：1280 × 720
- 页面 padding：上 20 / 下 20 / 左 64 / 右 64
- **A · 标题块**：y = 20–120px，高 100px，主标题 34px bold，左侧 4px 主色竖条（宽 4 × 高 40，与主标基线对齐），A 区禁止放图片
- **B · 内容区**：y = 132–656px，高 524px
- **C · 页脚条**：y = 664–700px，高 36px；左侧「多AI协助系统 · 三大功能设计总方案」14px `#64748B`；右侧页码 `NN / 14` 14px `#64748B`
- 封面 / 章节扉页 / 结束页可自定义版式，省略 A 区标题块；页码仍保留在 C 区（封面除外）

## 2. 色彩系统（4 色池 + 中性）
| 角色 | HEX | 用途 |
|:--|:--|:--|
| 主色 · 深海军蓝 | `#0B2545` | 标题块竖条、封面/章节大字底色块、深色卡片底、强调文字 |
| 辅色 · 科技蓝 | `#2E7CF6` | 流程节点、图标、分隔线、图表主系列 |
| 强调色 · 青绿 | `#00C9A7` | 巨型数字、裁决/校验节点、核心高亮、CTA 条 |
| 中性底 | `#F4F7FB` | 卡片底、页面浅底分区 |
| 文本 / 灰 | `#14202E` / `#64748B` | 正文 / 次要说明 |

**面积分配**：主色 ≤ 55%（多为深色块与文字），辅色 ≤ 30%，强调色 ≤ 10%（Hero 页可到 15–20%），中性占剩余。
- Supporting 页：强调色 ≤ 5%，辅色 ≤ 20%
- 页面映射表中逐页标注实际分配

**渐变与半透明**
- 深色块渐变：`linear-gradient(135deg, #0B2545 0%, #123C6E 100%)`
- 主色浅覆盖：`rgba(46,124,246,0.08)`（卡片头、区域底）
- 强调浅覆盖：`rgba(0,201,167,0.10)`（校验/裁决节点底）
- 卡片阴影：`0 4px 20px rgba(11,37,69,0.08)`
- 封面底图蒙版：`rgba(11,37,69,0.55)`

## 4. 密度与留白门禁
- 常规内容页留白 ≤ 30%；Hero 页允许 30–40%；章节扉页 45%
- 卡片填充率 ≥ 85%；高 ≥ 380px 的卡片正文 ≥ 100 字
- 卡片尾部元素用 `marginTop: 'auto'` 锚定底部
- 焦点留白：巨型数字 / 大图周围 ≥ 40px
